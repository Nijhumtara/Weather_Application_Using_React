# Weather Application Using React JS

A weather application built with React JS and Vite that allows users to search and view real-time weather information for any location.

## 🛠️ Built With

- **React JS** — Frontend framework
- **Vite** — Build tool
- **Weather API** — Real-time weather data

## 🚀 Getting Started

### Install dependencies
```bash
npm install
```

### Run the app
```bash
npm run dev
```
